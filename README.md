# Factor Climb

A cliff-climbing platformer for practicing **missing factors in single-digit multiplication** (for example, `6 × ? = 54`).

Students run and jump up floating ledges. At the top of each climb are three numbered platforms. Landing on the missing factor saves their progress and builds the next part of the climb. Landing on a wrong number makes the platform crumble, shows the correct fact, and brings that fact back again a few ledges later.

## Play

Open `index.html` in any modern browser. No install or build step is needed.

To host it for students, turn on **GitHub Pages** for this repository (Settings → Pages → Deploy from branch → `main` / root). The game will then be at `https://<your-username>.github.io/Missing-Factor-Multiplication/`.

## Controls

| Action | Keyboard | Touchscreen |
| --- | --- | --- |
| Move | ← → or A / D | ◀ ▶ buttons |
| Jump | Space or ↑ | JUMP button |
| Pause | P or Esc | Pause button |

## Teacher settings

- **Times tables:** choose any of 1–9 (default 2–9).
- **Climb time:** 2 minutes, 4 minutes, or no timer.

## Results screen

After each round students see height climbed, facts solved, accuracy, best streak, and a **Facts to practice** list of every fact they missed.

## What's being practiced

- Three forms: `a × ? = p`, `? × a = p`, and `p = a × ?`
- Wrong answer choices are numbers close to the answer, plus sometimes the factor already shown in the problem (a common mix-up)
- Missed facts are put back into the game for review
